ELISA OPTION B - DEPLOY

This agent uses:
- Deepgram Nova-3 via LiveKit Inference for STT
- OpenAI GPT-4.1 mini for the LLM
- ElevenLabs TTS plugin for the custom voice (API key passed explicitly)
- Silero VAD

LiveKit Cloud secrets required:
OPENAI_API_KEY
ELEVEN_API_KEY
ELEVENLABS_VOICE_ID
LIVEKIT_AGENT_NAME=elisa

IMPORTANT: Do not put API keys in the ZIP or Git repository.

Deploy from this agent directory with:
lk agent deploy

After deployment, start a NEW test session. The agent explicitly passes ELEVEN_API_KEY to the ElevenLabs plugin. The custom/community voice is kept on the direct ElevenLabs plugin path.
