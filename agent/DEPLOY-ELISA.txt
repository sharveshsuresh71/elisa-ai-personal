ELISA deployment

1. Copy .env.example to .env and fill in LIVEKIT_API_KEY, LIVEKIT_API_SECRET,
   LIVEKIT_URL, and ELEVEN_API_KEY. Never share .env.
2. From this agent folder run:
   npm ci
   npm run build
   npm start
3. Wait for "registered worker". Stop with Ctrl+C.
4. Deploy:
   lk agent deploy . --secrets-file .env
5. Check:
   lk agent status
6. It must say Running.
